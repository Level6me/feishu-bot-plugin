# 🧩 Antigravity Feishu Bot 官方插件仓库 (Plugin Store)

包含由 Antigravity 官方维护的飞书机器人解耦扩展插件库。

## 📦 包含插件列表

| 插件名称 | 插件 ID | 版本 | 注册指令 | 描述 |
| :--- | :--- | :--- | :--- | :--- |
| **🖥️ 服务器巡检与健康报告** | `server_health` | `v1.0.0` | `/sysinfo`, `/health` | 实时监控 CPU 负载、内存率、磁盘余量 |
| **⏱️ 计划任务与定时调度** | `cron_scheduler` | `v2.0.0` | `/cron`, `/schedule` | Cron 倒计时后台任务与自动巡检看板 |

| **📝 备忘录与随手记** | `notes_manager` | `v2.0.0` | `/note`, `/notes` | 随时快速记录与检索个人随手记条目 |
| **🔄 系统在线热更新** | `system_updater` | `v2.0.0` | `/update` | 一键检查 GitHub 云端最新代码并热更新 |

## 📥 安装使用
在机器人中发送 `/plugin` 面板，选择【🏪 插件源与商店】，点击「一键安装」或复制本仓库 URL 提交即可。
