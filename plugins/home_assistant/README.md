# 🏠 Home Assistant 全屋智能控制台

专为 `feishu-bot-plugin` 与 `antigravity-feishu-bot` 打造的分区域全屋智能控制插件。

---

## ✨ 核心特性

1. **分区域设备控制面板**：
   - 界面简洁清爽，支持按“全部 / 客厅 / 主卧 / 次卧 / 厨房 / 玄关”快速切换；
   - 实时呈现全屋设备状态（💡 开启 / ⚪ 关闭 / ❄️ 制冷 / 📺 运行）。
2. **零刷屏局部交互式卡片（In-Place Patching）**：
   - 点击卡片上的开关、调温、切换区域按钮时，飞书卡片原地秒级翻转状态，绝不发送多余消息刷屏。
3. **秒级免思考极速控制（Sub-50ms FastPath）**：
   - 通过 `on_before_ai` 本地意图解析引擎，对“开客厅灯”、“关空调”、“全屋关灯”等指令实现 **< 50ms 零模型延迟直达执行**，彻底阻断大模型长思考。
4. **全自动装配与自愈式配置**：
   - 支持全全新装环境，仅需在飞书卡片中输入 Token，自动完成连通性探测、全屋硬件拉取、以及反向向系统写入 `~/.gemini/config/mcp_config.json`。

---

## 🚀 常用指令

| 指令 | 说明 |
| :--- | :--- |
| `/ha` 或 `/home` | 唤出全屋智能分区域控制看板 |
| `/ha setup` | 唤出交互式配置与连通性诊断中心 |
| `/ha token <Token>` | 一键保存并绑定 HA 长期访问令牌 |
| `/ha sync` | 全量重新同步全屋硬件与区域映射 |
